## 损坏页滚轮 + MSIX

- 根因：`ZoomPanView.OnPointerWheelChanged` / `OnPointerPressed` / `OnPointerReleased` 以 `_bitmap != null` 为前提，解码失败页直接丢弃事件。
- 修复：翻页（滚轮/点击）与位图解耦；缩放/平移仍要求位图；`HandleWheel` 抽取 + `SimulateWheel` 测试钩子。
- 回归：合成库 0 字节页 3/9 → 4/9，`handled=true`（JIT 与 AOT 均通过）。
- MSIX：`packaging/EhViewerReader.Msix`，AOT 发布 → 暂存（剔 PDB）→ BuildTools `MakeAppx`；产物 15.8 MB；`MinVersion 10.0.17763`、`runFullTrust`、x64。
- 打包布局在 `artifacts/msix/{aot,layout}`，不占用 `artifacts/win-x64-aot`（应用运行时可打包）。
- 注意：MakeAppx 要求布局内清单名为 `AppxManifest.xml`；版本用 XmlPoke 注入。

## 多数据源 + 版本管理 + 解决方案修复

- **slnx**：`EhViewerReader.slnx` 增加 `/packaging/EhViewerReader.Msix`。打包工程在 `BuildingSolutionFile=true` 时跳过 AOT+MakeAppx 并打印提示（`PackMsixOnBuild` 属性，直接构建或 `-p:PackMsixOnBuild=true` 仍出包）。
- **数据源模型**：`LibrarySource{Id,RootPath,Name,Enabled,LastScanUtc}`；`AppSettings.Sources` + `PreferredSourceByWork`；schema 1 的 `LibraryRoot` 在 `Normalize()` 迁移为第一个源（离线盘也保留）。路径统一 `TrimEndingDirectorySeparator`。
- **缓存**：`library-cache-<sourceId>.json`，旧 `library-cache.json` 首次被收养；`LibraryCacheStore.Load/Save(sourceId,...)`。
- **跨源合并**：`Core/Scanning/LibraryMerger` + `WorkId`（gid 或 `dir@pathHash`，与旧 StableId 同形）；只在 ≥2 个不同源时合并，同源重复 GID 不合并；多源时 `StableId` 追加 `@sourceId`。
- **进度**：读写 `WorkId`，读时回退 `StableId`；换副本进度不丢。
- **UI**：卡片 `×N` 角标（Border+Tapped，不用 Button）、`VersionsWindow`（用此版本阅读/设为默认/打开文件夹）、详情页数据源/版本行、设置页数据源列表。
- **踩坑 1**：`ScrollViewer.Padding` 不扣减子元素可用宽度 → 内容按窗口宽测量后右侧被裁。改为内层 `Border Padding`（主/设置/详情/版本窗口）。
- **踩坑 2**：卡片浮层里的 `Button` 会让相邻 `TextBlock` 在容器复用时保持 0 宽；折叠→显示的角标也会。改为纯 Border 浮层 + `Galleries` 替换后 `ItemsRepeater.InvalidateMeasure()`；冒烟断言 `firstCardBadgeOk`、`emptyBadges`。
- 验证：44 单元/集成测试通过（真实库 1m42s）；冒烟 2 源/31 作品/3 多版本卡/7 副本；AOT 22.9 MB 冒烟通过。
- README 全面重写：新增截图预览表、多数据源/版本管理专节、许可说明；数字更新（AOT 22.9 MB、MSIX 15.9 MB、44+34 测试）。
