
## 2026-11-10 · 迁移 EhViewer 在线功能 + 导航重构

**目标**：把 Ehviewer_CN_SXJ 的在线能力迁移到 Avalonia 桌面端，并用左侧导航重构 UI；下载作为独立可配置数据源。

**新增（Core）**
- `Online/HtmlLite.cs`：自研容错 HTML 解析器（无第三方依赖，AOT 安全）。
- `Online/EhUrls.cs` / `EhModels.cs` / `EhParser.cs` / `EhClient.cs` / `EhHttp.cs`：
  - 列表（首页/热门/关注/排行/收藏/历史/搜索）、详情（`#gdd` 行、`#gdc` 分类、`#taglist` 命名空间）、页面列表（sprite 预览、`/s/{hash}/{gid}-{page}`）、图片页（`img#img` + `nl('keystamp')` 原图）。
  - 登录（forums 表单）、Cookie 导入/持久化、ExHentai 权限探测、站点切换。
  - 代理（None/System/HTTP/SOCKS5）、图片分流、DoH（ConnectCallback）、自定义 hosts；视图页请求串行限速 260ms。
- `Download/`：`DownloadManager` 独立队列（并发画廊/页面、暂停/重试/续传、归档、EhViewer 兼容目录 `.thumb`/VERSION2 `.ehviewer`），`downloads.json` 持久化。
- `AppSettings` 新增 `Account/Network/Download`、搜索历史/保存搜索；计算属性加 `[JsonIgnore]`（避免 activeSources/hasCredentials 落盘）。

**App**
- `ShellViewModel` + `MainWindow` 导航壳（在线/搜索/收藏/历史/下载/本地库/设置），页面控件按 VM 缓存。
- 新页面：`OnlineFeedPage`、`SearchPage`、`DownloadsPage`、`SettingsPage`、`OnlineGalleryWindow`；`LibraryPage` 承接原 MainWindow 逻辑。
- `IReaderSource` 抽象（`LocalReaderSource`/`OnlineReaderSource`），阅读器支持在线页面缓存与连续模式尺寸回填。
- `OnlineImageService`：缩略图/页面磁盘缓存 + LRU 清理；`--online-probe` 诊断；`--ui-smoke` 逐页与在线详情截图。

**验证**：60 单测通过；AOT 发布 0 裁剪警告（29.7MB exe，AOT 下 --online-probe 通过）；`--online-probe` 首页 25 项 / 详情 15 标签 / 页列表 20 / 图片直链 / 缩略图 22KB；`--ui-smoke` 全绿。

**关键坑**
- `CookieContainer(4096, 8192, 64)` 非法（perDomain < 4096）。
- E-H 视图 URL 是 `gid-page` 而不是 `page-gid`。
- 详情页老结构（`div.cs` 带 Category:）已失效，改为 `#gdd` 表 + `#gdc` 无标签分类。
- 列表默认 Compact 视图把标签 chip 放在标题 `<a>` 内，标题必须取 `.glname .glink` 的文本。
- Avalonia `ContentControl` 切换页面用「控件缓存 + 显式 DataContext」比 DataTemplate 更可控（还能给冒烟测试暴露控件）。

## 第三轮 · 收尾修复

- 子窗口（在线详情 / 种子 / 归档）根 `Grid` 必须显式设置 `Background`：`RenderTargetBitmap.Render(window.Content)` 不含 Window 背景，透明像素上的文字抗锯齿会在 PNG 中变成重影，且看起来像标题被裁切。
- `UiSmokeService.SaveScreenshot` 改为预热 + 正式两次渲染；详情截图前把 ScrollViewer 复位到顶部（评论框聚焦会滚动正文）。
- 设置页不再在构造时解析 2.5 MB 标签库，只读 settings 里的 count/version；真正打开详情时才懒加载。
- 评分按钮保持可点击（未登录点击给出提示），避免禁用后无解释。

## 第四轮 · 登录修复（Cloudflare → 网页登录）

**根因**：`forums.e-hentai.org` 对任何非浏览器客户端返回 `403 + Cf-Mitigated: challenge`（"Just a moment…"），所以密码 POST 永远失败（旧界面只显示「登录失败：HTTP 403」）。这也解释了原版为什么用 WebView。

**实现**
- `Services/BrowserLogin.cs`：查找 Edge/Chrome → 一次性 `--user-data-dir` + `--remote-debugging-port` 启动 → `/json/list` 找页面 → `ClientWebSocket` 连 CDP → `Storage.getCookies` 轮询；结束后 `Kill(entireProcessTree)` + 删除临时配置；启动时清理 1 天前的 `%TEMP%\ehviewer-login-*`。
- `ViewModels/WebLoginViewModel.cs` + `Views/WebLoginWindow.axaml`：状态机、当前页面标题、切换/重启浏览器、手动 Cookie 折叠区。
- `EhClient.CompleteBrowserSignInAsync`：只导入认证 Cookie（排除 `cf_clearance`）→ `home.php` 验证 → 镜像 `igneous` → 探测 ExHentai → 落盘；`VerifySignedInAsync` 连发两次（覆盖 meta refresh）。
- Cookie 解析支持 `a=b; c=d` / `Cookie:` 头 / `Copy as cURL` / JSON / DevTools 表格（tab 分隔）。
- 设置页账号区改为「网页登录（推荐）」+ 密码登录折叠 + Cookie 折叠；侧栏「登录」直接开窗口（已登录时隐藏）。
- 新增 `--login-probe`：Edge 无头启动 → CDP → 注入假 Cookie 读回 → 假 Cookie 被站点拒绝。

**验证**：74 单测；`--login-probe` 2 条注入读回 + 假 Cookie 被拒；`--ui-smoke` 走 shell 命令打开窗口并截图 `web-login.png`，关闭后无残留进程/配置；AOT 30.7MB、0 裁剪警告、AOT probe 通过。

**坑**
- `Theme.axaml` 里仍有 7 处 `SemiBold`（上一轮漏改），统一改 `Bold`。
- DevTools 表格是 tab 分隔，不能按 `=` 解析；`ipb_*` Cookie 的域是 `.e-hentai.org`（rank 2），子域 Cookie 作为兜底（rank 1）。
- 无头 Edge + CDP 在 Cloudflare 页面上仍能读 Cookie，但登录必须用有头窗口。

## 第五轮 · 历史/收藏状态/本地标识/语言

**历史改为本地**：新增 `HistoryViewModel` + `HistoryPage`，数据来自 `MainViewModel.SnapshotAllWorks()` + `ProgressStore`（`!IsUnread`，按 LastReadUtc 倒序）。行内显示封面/标题/进度条/最近阅读；「继续阅读」先导航到本地库再执行 `OpenGalleryCommand`（LibraryPage 才持有阅读器窗口的处理器）；「移出历史」同时清 WorkId 与旧 StableId。站点历史保留为页头按钮（浏览器打开）。`ShellViewModel.History` 类型已改，`ToggleSiteAsync`/`ApplyLoginResult` 里旧的 `LoadAsync/RefreshProgress` 调用已移除。

**收藏状态**：详情页 `#favoritelink` 文本（非 "Add to Favorites" 即已收藏）是权威信号；槽位从 `gallerypopups.php?act=addfav` 的 selected option 读（原来错用了 `act=popup`，永远 -1）。修改收藏统一 POST addfav，删除用 `favcat=favdel`（站点无 deletefav）。槽位未知时显示「已收藏（分类未知）」伪选项。

**本地副本**：`MainViewModel` 维护 gid→item 索引（`RebuildLocalIndex` + `LocalIndexChanged`）；在线卡片封面左上角「已在本机」，详情左栏「本地库已有此作品（N 个版本）」+「在本地库中打开」。`IOnlineHost` 增加 `HasLocalCopy/OpenLocal/GetLocalVersionCount`。

**语言**：列表标签 `language:japanese` → 卡片右下角 chip「日文」；注意标签是小写，映射前要先按 `KnownLanguages` 大小写不敏感归一。

**验证**：76 单测；`--ui-smoke` 的 `localHitCard={inLocal:true,language:中文}`、`localHitDetail.banner=true`、历史页 1 条记录；6,315 项虚拟化仍 21 容器。
