
## 2026-11-10 · 迁移 EhViewer 在线功能 + 导航重构

**目标**：把 Ehviewer_CN_SXJ 的在线能力迁移到 Avalonia 桌面端，并用左侧导航重构 UI；下载作为独立可配置数据源。

**新增（Core）**
- `Online/HtmlLite.cs`：自研容错 HTML 解析器（无第三方依赖，AOT 安全）。
- `Online/EhUrls.cs` / `EhModels.cs` / `EhParser.cs` / `EhClient.cs` / `EhHttp.cs`：
  - 列表（首页/热门/关注/排行/收藏/历史/搜索）、详情（`#gdd` 行、`#gdc` 分类、`#taglist` 命名空间）、页面列表（sprite 预览、`/s/{hash}/{gid}-{page}`）、图片页（`img#img` + `nl('keystamp')` 原图）。
  - 登录（forums 表单）、Cookie 导入/持久化、ExHentai 权限探测、站点切换。
  - 代理（None/System/HTTP/SOCKS5）、图片分流、DoH（ConnectCallback）、自定义 hosts；视图页请求串行限速 260ms。
- `Download/`：`DownloadManager` 独立队列（并发画廊/页面、暂停/重试/续传、归档、EhViewer 兼容目录 `.thumb`/VERSION2 `.ehviewer`），`downloads.json` 持久化。
- `AppSettings` 新增 `Account/Network/Download`、搜索历史/保存搜索；计算属性加 `[JsonIgnore]`（避免 activeSources/hasCredentials 落盘）。

**App**
- `ShellViewModel` + `MainWindow` 导航壳（在线/搜索/收藏/历史/下载/本地库/设置），页面控件按 VM 缓存。
- 新页面：`OnlineFeedPage`、`SearchPage`、`DownloadsPage`、`SettingsPage`、`OnlineGalleryWindow`；`LibraryPage` 承接原 MainWindow 逻辑。
- `IReaderSource` 抽象（`LocalReaderSource`/`OnlineReaderSource`），阅读器支持在线页面缓存与连续模式尺寸回填。
- `OnlineImageService`：缩略图/页面磁盘缓存 + LRU 清理；`--online-probe` 诊断；`--ui-smoke` 逐页与在线详情截图。

**验证**：60 单测通过；AOT 发布 0 裁剪警告（29.7MB exe，AOT 下 --online-probe 通过）；`--online-probe` 首页 25 项 / 详情 15 标签 / 页列表 20 / 图片直链 / 缩略图 22KB；`--ui-smoke` 全绿。

**关键坑**
- `CookieContainer(4096, 8192, 64)` 非法（perDomain < 4096）。
- E-H 视图 URL 是 `gid-page` 而不是 `page-gid`。
- 详情页老结构（`div.cs` 带 Category:）已失效，改为 `#gdd` 表 + `#gdc` 无标签分类。
- 列表默认 Compact 视图把标签 chip 放在标题 `<a>` 内，标题必须取 `.glname .glink` 的文本。
- Avalonia `ContentControl` 切换页面用「控件缓存 + 显式 DataContext」比 DataTemplate 更可控（还能给冒烟测试暴露控件）。

## 第二轮 · 完整实现（在线功能补齐）

**新增能力**
- 种子：`EhParser.ParseTorrents`（每个 `<form>` 一条）、`DownloadTorrentAsync`（ehtracker 直链，bencode 已验证）、TorrentWindow（保存/复制链接）。
- 评论：`ParseComments`（`#cdiv .c1` → id/user/posted/score/text/votes）、`GetCommentsAsync(?hc=1)`、`PostCommentAsync`（详情页表单）、`VoteCommentAsync`（api.php `votecomment`）。
- 评分：`RateGalleryAsync`（api.php `rategallery`，1–5 星→2–10），使用详情页 `apiuid/apikey`；匿名禁用。
- 归档：`ParseArchivePage`（`hathdl_form` 的 `or` + `do_hathdl` 选项）、`RequestArchiveAsync`（`hathdl_xres`）、`ParseArchiveResult`（zip / H@H / 排队）、ArchiveWindow 下载到 `下载根/archives`。
- 标签翻译：`TagTranslationParser` + `TagTranslationService`（db.text.json.gz，gzip 解压、44,873 条、落盘 `tag-translations.json`）；设置页一键更新；标签 chip 显示「命名空间:中文名」。
- 过滤：`FilterRule` + `EhFilter`（隐藏/仅显示；标签/标题/上传者）；列表解析补 `div.gt[title]` 标签；首页/搜索/收藏/历史生效并显示过滤数。
- 收藏分类命名（本地显示名，10 个）+ 收藏夹内搜索；在线阅读原图开关（缓存键区分 orig）。

**关键修复**
- `FontWeight=SemiBold` 在 Microsoft YaHei UI 上触发 Skia 合成加粗 → 截图/屏幕中文重影；全项目改为 `Bold`。
- Avalonia 12 剪贴板 API：需 `using Avalonia.Input.Platform` 才能用 `SetTextAsync` 扩展。
- AOT 诊断报告：匿名对象会退化为字符串；`OnlineProbeService` 改字典，AOT 输出结构化 JSON。
- `StorageJsonContext` 改为 public（App 项目要用）。

**验证**：70 单测；`--online-probe` 种子 5,997B bencode / 实时评论 / 标签库 44,873；`--ui-smoke` 新增设置-在线、种子、归档截图；AOT 30.3MB、0 裁剪警告、AOT probe 通过。
