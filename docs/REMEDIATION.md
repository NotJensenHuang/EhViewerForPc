## 本次交互修正（后续反馈）

- 设置 → 下载 → 浏览选择目录 → 选择「仅更改后续下载位置」或「搬迁已有下载」。前者默认启用，接受已有内容的目录，保留旧任务与旧数据源；后者要求空目标目录，进度与取消入口位于设置页底部。实际搬迁期间锁定导航并阻止退出，避免写入冲突；传输中的归档需要先完成。仅保存新位置时无需等待现有归档结束。
- 账号页按当前会话切换：登录后展示账号信息和更换账号，隐藏登录引导、密码登录与 Cookie 导入；退出后恢复登录入口。
- 压缩尺寸配置参考[上游 EhConfig](https://github.com/xiaojieonly/Ehviewer_CN_SXJ/blob/master/app/src/main/java/com/hippo/ehviewer/client/EhConfig.java)，沿用 xr 尺寸与 oi 原图开关，不提交账号设置表单。

## 取消迁移与仅保存选项

旧实现为整体重命名先删除空目标文件夹，并在回滚时清理复制产物，没有记录目标文件夹原本是否存在。现在在迁移日志中记录目录所有权和条目清单：已有空目标文件夹始终保留，同盘按条目重命名，跨盘先在应用临时目录复制校验后发布。取消只回滚本次操作，原有目标目录及用户另行添加的文件保留；中断的按条目移动也可恢复。

新增「仅更改后续下载位置」模式，保存时不移动数据、不改写旧任务和旧下载归档的路径，新目录可非空；配置失败恢复原设置。本地库保留有内容或任务的旧源并添加新源，以继续访问原有文件；空的默认旧源只移除登记，物理目录保留。

不搬迁保存已通过 Windows UI Automation 实际点击验证：默认模式为「仅更改后续下载位置」，按钮为「保存设置（不搬迁）」；保存到已有合成文件的新目录后，原目录文件、目标原有图片与说明文件全部保留，配置中的新旧数据源路径正确，未创建迁移日志。

## 验证结果

- 自动测试 **112/112 通过**。新增用例覆盖并发上限、标签目录扫描/缓存、原图解析、截断列表、HTML 错误响应与重试、缓存复用、取消删除时序、设置合并与草稿、在线历史、收藏保留、紧凑尺寸持久化、图像内存预留与 LRU。
- 后续反馈修复的完整 UI 冒烟约 **63.95 秒**，使用独立数据目录与几何图形合成资料库；检查深色/浅色、600px 窗口、详情、阅读器、历史、下载、归档和登录页。
- 合成库 **6346** 项，视口内创建 **21** 个卡片容器；历史 **6346** 项仅创建 **7** 个封面控件；下载 **2000** 项仅创建 **6** 行。
- 横向翻页 2/9 → 3/9，滑块 5.5 的位置在三次采样中保持 1705.7px；关闭重开恢复 5/9。切换方向后连续滚动与尺寸复用的专项回归通过。
- 同一作品重复打开只保留一个阅读器；返回后资料库滚动位置保持 640px。30 帧合成 GIF 实测约 **16.6 fps**，最大帧间隔 **64ms**，无中段停顿。
- 热缓存封面连续加载 **100** 次，全进程托管分配增量约 **845,176 字节**；旧路径仅每次创建 256×384×4 数组这一部分的估算为 **39,321,600 字节**。这是单机冒烟采样，包含其他线程分配，不是完整的前后性能基准。
- 测试结束的 CPU 图像预算预留归零；预算不代表 GPU、Skia 内部或整个进程的工作集上限。
- 单窗口 UI 回归：阅读页实际可见返回按钮为 **1**，独立窗口为 **0**；沉浸时侧栏隐藏，手动收拢有效；登录会话下不再显示登录引导。合成资料库的目录搬迁确认文件、任务、数据源路径同步，无 GID 作品的进度与收藏保留。
- Windows UI Automation 实际点击验证：收拢侧栏、打开阅读页、沉浸后按 Esc 返回，以及设置页「保存并搬迁下载」均正常；磁盘文件与持久化下载根目录、本地库根目录一致。
- 最终 Windows x64 **NativeAOT + Trim** 发布成功，发布后的 EXE 实际运行完整 UI 与目录搬迁回归通过（退出码 0，约 63.13 秒）；Linux x64 **托管发布**成功。

## 验证边界
