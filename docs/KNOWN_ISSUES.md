# 尚未验收的漫画翻译能力

- 两款公开日中 GGUF 候选的完整权重需要核验与真实推理。页面 OCR 仍有受控的框数量上限，对密集图页可能需要分图或扩大检测预算再验证。Qwen3 4B、8B Q4 需要在作者页面取得访问许可后，用本地评测入口测量。缺少证据前保留试用标签和手动选择。
- 缺少 200 条人工确认翻译案例的盲评和同页端到端真人评审。临时上下文只引用原文与通过结构校验的译文。项目级角色身份、人工锁定术语和按词条重译属于 §4.4 和 §10 的未完成产品验收项，不能靠自动生成术语或结构成功状态替代。
- 目前应用只有日语 → 简体中文的声明支持方向，源语自动识别、多语言回退与多模型自动路由尚未接入。参见[语言覆盖](LANGUAGE_COVERAGE.md)。
- 阅读器使用可切换的多行横排覆盖，没有整卷队列、断点恢复、整页译图导出、竖排中文、SFX 专门排版或复杂背景原文修复。合成擦除基准不能代表真实漫画线稿的修复效果。
- RTX 8 GB 的显存压力、批次降级和长期稳定性尚未验收。Windows 10 和其他 GPU 未进行本轮桌面验证。
