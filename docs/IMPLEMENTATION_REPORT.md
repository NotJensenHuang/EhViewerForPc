# 漫画翻译质量改动

- 保留原 C# 阅读器、模型资产安装和无窗子进程调用。两份公开 GGUF 候选共用固定版本的 llama.cpp Vulkan 桥，各自使用对应角色模板和采样配置。两个需要授权的 Qwen3 模型使用同一桥的隔离评测入口。普通阅读器仅接受公开选项与简体中文目标。
- 识别过程保留合并前四边形及其分数、原框和合并区域 ID、首次文本、纠错候选和最终置信度。低置信、空识别区域保留为待复核观察，不覆盖原图。生产 OCR 默认仍用已有 PP-OCRv5，候选及实际模型测试见[OCR 模型评估](OCR_MODEL_EVALUATION.md)。
- 当前区块参考同页最多四个相邻区的原文，其中已经通过结构校验的前置区块同时提供译文。另可参考同一阅读器上一相邻页最多三个原文与译文。参考限长，超上下文时按当前句重试。引用按阅读器会话与连续页号隔离，父进程只有成功收到并解析上一页且取消信号未设置，才允许下一请求引用该页。作品、目标语向和模型变化隔离上下文。上下文模式重新计算返回页，以免已有内存结果携带另一次阅读过程的上下文。
- IPC 给译文区域分配顺序 ID，检查数量边界、区域顺序、坐标和输出状态。空译、截断和超长输入保留原文并继续译下一块，异常草稿限长保留；不同原文的疑似重复译文、照抄、仅有日语假名的疑似错语向，以及有文字原文被转成纯标点或符号的结果可查看，保持原图。纯标点原文不受符号规则拦截。原生工作进程或整页 OCR 失败仍由现有整页重试处理。
- 阅读器仍提供区域覆盖与可复制结果。复杂背景掩膜与修复的可重复 CPU 评估见[图像修复对照](漫画图像修复对照-2026-11-26.md)。未把修复基准直接接入阅读器。
