# 托盘与阅读检索界面修复（2026-11-15）

> 后续更正：本报告对应 `b823e68`。当时只验证了托盘对象与菜单命令，未覆盖 Avalonia 的应用级注册，实际原生图标未创建；此前的“界面”入口也不准确。托盘、入口和顶部按钮结论以[后续修复记录](托盘注册与增量更新修复-2026-11-15.md)为准，其他回归证据保留。

## 本次行为

| 问题 | 调用链与原因 | 修复后的行为 |
| --- | --- | --- |
| 重复补页像重新扫描 | 未变化的单副本核对仍发送 `LocalCopyChecked`，重新建立全库 GID 匹配表并触发图片索引维护；空批次 / 重复任务仍触发队列通知，暂停 / 运行状态进入目录导入签名 | 原目录仍按需要核对；页状态无变化不发布副本更新，空批次不调度队列，重复任务不重复通知；目录导入仅关注页数、总数、路径和完成状态 |
| 阅读按钮与 ComboBox 不等高 | 原生 CommandBar 为 48 DIP 内容和上下 6 DIP 底板留白，只设置控件 Height 会把底板压缩到 20 DIP | 使用局部原生尺寸资源把控件、底板、内容统一为 32 DIP；图标为 20 DIP，窄窗口图标按钮宽 36 DIP，保留原生状态色 |
| 本地重试未下载 | `LocalReaderSource.CreateRequest(refresh: true)` 仍只生成本地解码请求，页候选也是打开时的快照 | 明确的「重试本页」经 `DownloadManager` 只重下载选中原始页，等待同目录在途写入，验证传输后原子替换该页；失败保留旧文件，其他图片及元数据不变 |
| 剪贴板预览变黑白 | `LoadBytesAsync` 将 `GrayImage.Decode(...).EncodePng()` 当作界面预览 | 彩色预览单独解码，保留透明度与 EXIF；长边最多 2048 像素，裁剪仍使用方向校正后的原始坐标；检索保留原始输入和原有灰度流程 |
| 关闭窗口终止后台工作 | 主窗关闭直接释放文档，应用在 ShutdownRequested 阶段释放服务 | 加入 Windows 原生托盘，默认关闭到后台；托盘点击 /「显示窗口」恢复同一窗口和阅读页，下载与索引继续；设置的「界面 → 关闭窗口后后台运行」可改为直接退出 |

本地单页重试绕过本地页缓存及图片 URL 缓存，并维持站点视图请求节流。同目录 / 同页并发请求共享工作，不自动启动等待或暂停的整本下载；等待期间允许翻页，完成后不跳回。页面文件版本进入请求键，三种阅读模式同步更新候选、缺页占位与真实尺寸。没有可用原画廊链接、原始页号或属于自然文件名的副本，只重新载入文件并显示原因。

托盘不新增应用状态源。下载与索引仍由 AppServices 持有；托盘属于 App 的 UI 生命周期对象。恢复窗口不会再次初始化 Shell。显式退出和系统关闭不进入隐藏分支；取消退出时服务保持存活，实际退出后依次释放托盘、Shell 和 AppServices。诊断 / UI 冒烟不创建真实托盘。

设置字段 `CloseToTray` 默认为 true，沿用现有 AppSettings 源生成 JSON 和增量合并保存；设置、扫描缓存和图片索引版本不变。现有图片索引无需重建，本轮没有改变检索算法、索引格式或数据目录。
