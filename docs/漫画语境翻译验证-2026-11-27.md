# 漫画语境翻译验证

## 原页复现

用户原图是 1248 × 1760，参考译后图是 559 × 799。上一版 Windows x64 NativeAOT 从原图读出同一泡内从右到左三列「待って・・」「イッちゃう」「イッちゃうから：」，分别对应 OCR ID 3、2、1。关键动词读正确，末尾停顿被识别为冒号。OCR 的固定成对搜索窗超过 160,000 像素上限，令已有闭合纸底的左右文字拆成 [3,2] 和 [1]。因此旧阅读器收到「等等……要去了」与「因为要去了：」。

人工逐字校正后，用同一 JMangaTranslator-Fast 实测整泡、换成标准分句符号和逐块输入。整泡仍为「等等……要去了要去了……」，逐块仍为「要去了」。这次词义误判来自单气泡模型选错义项。缩减过大的搜索窗解决分组，语境推理处理词义，两项使用独立的回归。

## 语境候选和使用方式

项目选项 qwen3-4b-context 为官方 Qwen3 4B Q4_K_M，约 2.50 GB，经固定 SHA-256 校验。仅在用户选择并准备模型后启用，通过本地 llama.cpp Vulkan 推理。 [官方权重与 Apache 2.0 许可](https://huggingface.co/Qwen/Qwen3-4B-GGUF)

阅读器按气泡读取原文并提供同页附近对白。若保存有同一阅读会话中已成功处理的上一相邻页，可使用上一页原文。现有工作进程空闲约 30 秒会释放，不保留上一页原文到下一次启动。场景说明可在双语文本中手填，点击「结合语境重译」才传递，只用于本页，不写入应用设置或上传。双语文本按气泡标明实际参考过的语境范围，送回复核的结果也可核对来源。读者可以清空场景后重译。手填场景在同一页关闭再打开面板时可继续修改，切换页、切换模型或退出后清空。此模型读文字，画面事实需由已有对白或手填场景提供。

## 对照范围

固定闭合窗修复在最终 NativeAOT 对原图重新得到 [3,2,1] 和 172 × 216 的安全内框。默认路径和加装 BubblePop 的路径都得到同一分组，后者把三列标为同一 BubbleInstanceId。可选模型的 SHA-256、两相邻泡证据与误并测试见[气泡模型对照](漫画竖排气泡分组模型对照-2026-11-27.md)。该页修复不依赖额外图像模型。

独立 14 项真实权重对照包括人工转写原句、一般离开场景以及考试和掉落、电话和锁门等例子。人工转写无说明时，Qwen 在本机返回「等一下……要马上……马上……」。加上下文说明后则用「要高潮了」。同一「すぐかけるね」在电话和门锁两组合成上一页参考下改用不同动词，原 JManga 在两种场景下均输出「马上打过去」。仍有三个极短句送复核，拔牙与拔插头保留泛指，另有一次简体中文译文夹英文。该语料用于定位能力和失败点，没有独立人工大规模盲评。参见[模型同句对照](漫画语境模型同句对照-2026-11-27.md)。

## 原生桌面验收

Windows x64 NativeAOT 发布在 .qa/context-semantic-reader-aot-20261127。通过应用选中「Qwen3 4B 语境翻译（试用）」并点击「下载并准备模型」，使用实际作者发布权重的已下载本地缓存安装，应用核验后生成就绪凭据。已有用户选择不会自动更换。

在阅读器打开同一原页并点击「翻译本页」，实际 OCR 送入「待って・・イッちゃうイッちゃうから：」。未补说明时，主泡输出「等一下……我要马上高潮了，马上就要高潮了。」且未标额外参考。补充说话者当时感受的场景说明，点击「结合语境重译」，实际输出「待着……马上就要高潮了，马上就要高潮了。」并仅标明「本页手填场景」。换成较模糊的场景说明时，模型曾改为泛指「快不行了」，具体措辞仍有偏差。读者只需补场景，原台词仍由 OCR 采集。画外单字「二」保留待复核，借用同页对白的标记只随该区显示。

含真实 OCR 的合成场景在同一持久 worker 测得首张无上下文、顺序翻页上一页原文、同页重试保留上一页并使用手填、另开阅读会话不继承、同页另泡五条来源记录。记录为 .qa/translation-diagnose-f4b14/context-protocol.jsonl。个别句子虽确实消费上下文仍进入复核，相关记录只能验证引用和隔离，语义准确性以独立对照为准。以上验证未将整页图片作为报告附件，源页哈希前后一致。

桌面翻译及重译在 920 × 760 深色与 540 × 420 浅色实际操作通过。80 项翻译、OCR、阅读器定向回归全部通过，最终原生程序的阅读器回归退出码为 0。保留 Avalonia / FluentAvalonia 既有裁剪告警。
