# 漫画语境模型同句对照

在 Windows x64、NVIDIA GeForce RTX 5070 Ti 16 GB 和 llama.cpp Vulkan 上，使用官方 Qwen3 4B Q4_K_M 实测日语 → 简体中文。权重为 2,497,280,256 字节，下载后按清单核对 SHA-256。 [官方权重和 Apache 2.0 许可](https://huggingface.co/Qwen/Qwen3-4B-GGUF/tree/bc640142c66e1fdd12af0bd68f40445458f3869b)

## 同输入对照

前三行使用完全相同的日语，仅变更场景说明。后两行使用相同的「やばい、これ。」。语义按固定合成样本人工核对，未做盲评。

| 样本 | 应传达的意思 | 本机译文 | 语义核对 |
| --- | --- | --- | --- |
| 同事出发去车站 | 即将离开 | 待着……要来了，要来了…… | 错义 |
| 成年人亲密场景 | 即将达到高潮 | 待会儿……要高潮了、要高潮了…… | 关键义项正确，「待って」宜译为「等一下」 |
| 同句无场景 | 保留歧义或等待复核 | 等一下……要高潮了，要高潮了…… | 证据不足仍选定具体义项 |
| 月台赶电车 | 要赶不上电车 | 快点。要赶不上车了。 | 正确 |
| 骑车同伴先走 | 问对方是否先走 | 待会儿，先走吗？ | 移动义正确，开头语气偏差 |
| 医院心脏异常 | 心脏要撑不住 | 这样下去心脏会受不了了。 | 正确 |
| 厨房起火 | 危险或糟糕 | 待复核 | 未译出 |
| 称赞甜点 | 好吃或惊艳 | 待复核 | 未译出 |

模型返回「待复核」时，阅读器保留原文供核对。前期采样记录的后两行状态仍为 `ok`，随后修正了对不带括号的复核信号的识别。诊断入口的 `ok` 只代表返回可显示文本。

另用 Qwen3 4B Instruct 2507 的 2,497,280,448 字节 Q4_K_M 社区量化版跑了同句三组和多种提示。它在部分输出引入了源文与场景均未指明的生理细节，另一些提示对三个场景全部拒译，未纳入阅读器。当前官方 4B 权重能处理部分语境案例，极短多义句仍可能猜错。 [上游 Instruct 2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) [对照量化权重](https://huggingface.co/lmstudio-community/Qwen3-4B-Instruct-2507-GGUF)

## 本地复现

在设置中准备「Qwen3 4B 语境翻译（试用）」后使用下列命令。它将合成日语和手写场景送入本地翻译推理，跳过 OCR 和排版。

```powershell
$app = (Resolve-Path '<发布目录>/EhViewerForPc.exe').Path
$native = Join-Path (Split-Path -Parent $app) 'manga-native'
$cases = (Resolve-Path 'tools/translation/context-quality-cases.tsv').Path
$models = (Resolve-Path '<已准备的模型目录>').Path
& $app --manga-translation-worker --evaluate $cases $models $native qwen3-4b-context
```

本轮日志保存在本机忽略目录 `.qa/context-translation-20261127/`，合成样本在 [context-quality-cases.tsv](../tools/translation/context-quality-cases.tsv)。[原页和阅读器验证](漫画语境翻译验证-2026-11-27.md)
