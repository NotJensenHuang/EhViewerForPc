# 漫画气泡翻译验证（2026-11-25）

本次调整将相邻、方向一致且原图间有通道的 OCR 行列合并成一个送译区域。整框识别置信不足时，只对存在明确墨迹低谷的两列候选分列复查。覆字使用 OCR 联合框，在图片坐标中应用字体、目标文字方向和自然换行。单个区域超出模型上下文时，其余区域仍可翻译。

## Windows x64 发布

使用 Windows 11 x64（内部构建 26300）和 .NET SDK 11.0.100，发布到新的隔离目录。发布带上 DirectML 和 Vulkan 原生资产。Avalonia 与 FluentAvalonia 仍有既有剪裁和 COM 警告。

```powershell
dotnet publish src/EhViewerForPc -c Release -r win-x64 -p:PublishAot=true -o .qa/translation-bubbles-20261125/final-aot-r2
dotnet test tests/EhViewerForPc.ImageSearch.Ui.Tests -c Debug -p:PublishAot=false --filter 'FullyQualifiedName~MangaTranslation|FullyQualifiedName~MangaOcrDialogue'
```

聚焦测试通过 31 项，包含气泡分隔、译文排版、模型和语言设置、工作进程返回值与上下文边界。测试记录位于 `.qa/translation-bubbles-20261125/translation-focused-r2.trx`。

交付包为 `artifacts/EhViewerForPc-win-x64-manga-bubbles-20261125.zip`，大小 58,634,836 字节，SHA-256 为 `e279dc4b9a7d6176f78a1d7d5d1af3ae5ce55df400abc541e647eeda8c2df72c`。ZIP 的 29 项内容均逐项核对，23 项原生资产与发布清单中的 SHA-256 一致。解压后的主程序与发布目录主程序哈希一致。

## 原页 OCR 与模型

用户截图对应的 PNG 副本尺寸为 1280 × 1780。按原图坐标检查同一页，大气泡的五列从五个 OCR 区域合并成一个区域，左下气泡由未生成区域恢复为一个区域。用同一正式 AOT 工作进程和腾讯官方 Hy-MT2 7B Q4_K_M 各运行一次简中、英语，两个目标区域均返回译文。两个进程报告 DirectML 与 Vulkan0，耗时分别约 6 秒。正常结束后样本的大小、修改时间与哈希一致。模型权重 4,624,648,896 字节，各模型文件逐项按资源清单校验。原始记录位于 `.qa/ocr-bubbles/` 和 `.qa/translation-7b/verify-7b-summary.json`。 [腾讯官方 7B 权重](https://www.modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-7B-GGUF)

## 桌面阅读

解压后的正式 AOT 通过 `--reader-regression`，报告 `.qa/translation-bubbles-20261125/zip-reader-regression/ui-smoke.json` 显示 `passed: true`，覆盖合成图库导航及单页、纵向连续、横向连续与沉浸模式。

实际覆字用 LVT 驱动隔离诊断副本。诊断副本与正式源码仅有 `App.axaml.cs` 的冒烟模式留窗条件差异，使测试窗口能与已有用户实例并行。使用真实设置和阅读器页面，深色窗口实测 1.8B 简中与英语，在浅色 920 / 740 DIP 和深色 640 DIP 窗口实测 7B 英语。浅色 540 × 420 DIP 的最小窗口也实测 7B 英语覆字与原图开关。模型和语言均可保存，已存在的权重经设置页复核后生成当前模型的校验记录。实测可放大译文、切回原图并打开双语文本。连续两次还原原图的画面区域像素差均为零，源页的路径、长度、修改时间和 SHA-256 一致，工作目录未遗留图像快照。截图与桌面报告位于 `.qa/translation-bubbles-20261125/lvt-r2-dark/`，原页素材留在隔离测试目录。

## 全量 UI 套件

最终源码全量 UI 测试通过 198 项，两项阅读器重试测试失败。未修改的 HEAD 副本在同一环境复现两项相同的断言失败，分别为普通图片目录重试后未按期刷新和 HTTP 500 重试未按期显示错误。一次中间构建也出现以图搜图的 Avalonia WeakEvents 异常，最终源码复跑未出现。比较记录为 `.qa/translation-bubbles-20261125/translation-ui-final-r2.trx` 与 `.qa/translation-bubbles-20261125/head-baseline-full.trx`。

Windows 10、其他显卡及其余目标语言未做桌面实测。排版测试覆盖简中、繁中、英语与右到左段落方向。
