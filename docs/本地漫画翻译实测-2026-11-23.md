# 本地漫画翻译实测

2026-11-23

## 范围与样本

本次使用已安装的 `EhViewerForPc.Local` 1.1.0.0 注册及其用户状态目录确定来源。通过作品目录的 `Metadata.Language=Japanese` 与扫描缓存中无冲突的 GID 匹配，选取两个作品的三张正文位置静态页，其中一部补取一页。此处的日文标签来自作品元数据。

采用现有 JSON 目录与缓存。原页以只读流复制，副本与原页 SHA-256 一致后，仅从隔离副本生成定向的 RGB PNG 供后端读取。三页推理结束后，复核两部作品目录的当层文件与已读取的 JSON 库文件共 73 项，路径、大小和 UTC 修改时间均与抽取前一致，三个源页及其隔离副本 SHA-256 仍匹配。已安装应用在测试中没有启动。涉及原库的路径、哈希、图像、识别文字和译文保存在已忽略的 `.qa/`。

设备为 Windows 11 x64 build 26300、20 个逻辑处理器、31.8 GiB 内存和 GeForce RTX 5070 Ti 16 GiB，NVIDIA 驱动 617.14。以独立进程运行每张 PNG，模型加载与首次推理均计入阶段耗时。

## DirectML 文字检测和识别

隔离的 ONNX Runtime DirectML 1.24.4 使用相同的 worker 和模型执行 `--ocr-only`，三页均成功。GPU 事件数来自 ONNX Runtime profile，包含每次识别调用的节点事件。

| 样本 | 图像尺寸 | 区块 | 含假名区块 | DirectML 检测 / 识别事件 | OCR 耗时 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 | 1280 × 1656 | 27 | 0 | 258 / 17,880 | 2.969 秒 |
| 2 | 1280 × 1780 | 15 | 4 | 258 / 20,562 | 2.375 秒 |
| 3 | 1280 × 1780 | 4 | 1 | 258 / 3,874 | 1.219 秒 |

区块边界均在图像范围内。样本 1 的 OCR 输出没有假名，日语来源依据为作品元数据。样本 2 与 3 有五个区块包含假名，其中三个区块长度至少四个字符。未建立逐字人工标注或阅读顺序的对照真值，无法从这组结果计算 OCR 准确率。

## 日文识别到简中译文

三页在同一独立后端完成 PaddleOCR → Hy-MT2-1.8B Q4_K_M。DirectML 检测和识别事件与上表一致。llama.cpp b12650 在本机回环上启动，三页均记录 `Vulkan0`、实际卸载 33 层到 GPU。`llama-server --list-devices` 将该设备识别为 RTX 5070 Ti。三页串行运行，后续才开始界面验证。

| 样本 | 非空译文 / 区块 | OCR | 翻译含加载与收尾 | 后端合计 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 27 / 27 | 2.610 秒 | 3.750 秒 | 6.360 秒 |
| 2 | 15 / 15 | 2.625 秒 | 1.688 秒 | 4.313 秒 |
| 3 | 4 / 4 | 1.235 秒 | 1.406 秒 | 2.641 秒 |

五个识别出假名的区块均生成了含汉字且与原文不同的输出。46 个译文中有 35 个含汉字，有 23 个与 OCR 原文完全相同，其中 11 个原文不含汉字与假名。这组数据验证了推理链路和输出结构，译文忠实度、拒译覆盖率及整页读序仍需有标注的人工复核。

## 阅读器验证

最终 Windows x64 NativeAOT 发布物为 `.qa/translation-app-aot-20261123-r4/EhViewerForPc.exe`。使用隔离数据目录和默认后端入口，在 920 DIP 暗色窗口打开样本 2 的副本，再点击「翻译本页」。应用在 8.46 秒后显示 15 个区块和「GPU 已启用」，UI 自动化确认结果中含有日语假名，任务完成后临时目录为空，应用正常退出。真实页仅使用隔离副本。证据在 `.qa/translation-app-ui-r4/actual-gpu-ui-page2.json`。

翻译的暂存目录要求在本机磁盘，路径不能经目录联接重定向。以本机空目录作为替代目标测试链接方式的重定向，应用拒绝翻译，替代目录保持为空。路径探针覆盖普通 UNC、扩展 UNC 和实际映射的网络盘。证据在 `.qa/translation-app-ui-r4/rejected-ui.json` 和 `.qa/translation-app-ui-r4/path-probe-results.txt`。

r4 阅读回归通过。使用合成后端验证了取消、翻页、退出后的 worker 和子进程收尾，翻页后不会显示旧页结果，临时工作目录的内容均被移除。隔离阅读图库也通过了前后快照和哈希核对。相关记录在 `.qa/translation-app-protocol-r4/reader-regression/report/ui-smoke.json`、`.qa/translation-app-protocol-r4/lifecycle.json` 和 `.qa/translation-app-ui-r4/source-snapshot-result.json`。

Core 测试 293 项通过。全量 UI 测试 168 项中 166 项通过，失败项是 `ReaderRetryIntegrationTests.OrdinaryFolderRetryReloadsFilesWithoutInventingAnOnlinePage` 和 `ReaderRetryIntegrationTests.FailedRetryKeepsTheOriginalPageAndReportsTheError`。工作树与独立检出的 `a6cf489` 基线均复现这两项失败。对照报告在 `.qa/translation-head-baseline/current/reader-retry-current.trx` 和 `.qa/translation-head-baseline/baseline/reader-retry-baseline.trx`。

本次设备覆盖 Windows 11 x64 和一张 NVIDIA 显卡。Windows 10、其他 GPU、正式 MSIX 安装包、在线页翻译和系统级断网均未实测。

## 隔离复现

```powershell
./tools/translation/Install-Backend.ps1 -Destination .qa/translation-backend
python -I .qa/translation-real/run-real.py --ocr-only --tag real-directml
python -I .qa/translation-real/run-real.py --tag real-gpu
& ./.qa/translation-real/sample-readonly.ps1 -VerifyAfter
```

安装完成后，推理使用本地 PaddleOCR 权重和本机回环上的 llama.cpp。复现脚本和输入只在本次测试工作区保留，重跑可改用新的 `--tag`。

- 原页清单与最终快照分别在 `.qa/translation-real/source-samples.json` 和 `.qa/translation-real/source-after-run.json`。
- 匿名统计在 `.qa/translation-real/runs/real-directml/aggregate.json`、`.qa/translation-real/runs/real-gpu/aggregate.json` 与 `quality-summary.json`，完整原译 JSON 在 `real-gpu/` 下的 `page-*.private.json`。
- `.qa/translation-real/preview.html` 按页展示隔离原图、实际区块编号和对应原文、译文。Edge 无窗口验证通过，宽窗两栏与窄窗单列均可打开，区块与文本可双向跳转。预览只用本地资源，验证结果在 `.qa/translation-real/preview-verification.json`。
