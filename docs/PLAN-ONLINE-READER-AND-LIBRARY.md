## 4. 在线阅读先打开，并显示当前页加载进度

### 4.1 页面生命周期与按需索引

- `OnOnlineReadRequested` 不再在导航前等待 `GetAllPagesAsync`。先用已知标题、GID、token、总页数和历史位置创建阅读会话，马上推入现有 Frame。
- 阅读器外壳、页码和返回键立即可用。已知总页数时先建立稳定的逻辑页槽；不要把“尚未解析引用”当成“没有页面”。总页数未知则显示获取中，解析后补齐。
- 为在线阅读提供按需页引用解析器，允许 `OnlineReaderSource` 在引用未就绪时创建异步图片请求。按原始 1-based 页号索引，避免乱序返回改变页码。
- 优先当前阅读页，其次相邻页，低优先级再补索引；不得先扫完整画廊或下载所有图片。历史恢复到后部页时也应优先解析目标页所在预览分页。
- 预览页容量可能受站点设置影响，不写死每页 20/40 张。首次解析时取得实际分页信息；必要时扩展 `EhPageList`/解析器保存分页元数据，避免后部续读退化为全量顺序扫描。
- 复用详情已有的预览引用和持久页引用索引。索引有界、可失效重建，不持久依赖短时有效的图片直链。
- 阅读器中的等待任务绑定该阅读会话的取消令牌；退出、关闭文档、切换作品时取消等待。禁止晚到的完成回调重新打开已经离开的页面。
- 保留站点现有请求节流，以优先调度和去重改善延迟。当前页的等待不得排在大批后台预取之后。
- 单页、连续、横向模式均支持未加载页占位；真实尺寸到达后更新布局，保持当前页和页内偏移。`SaveProgress` 使用原始页号与预期总数，加载失败不能标成已读完。

### 4.2 真实进度链路

- 建议统一小型状态模型：`解析页面 / 等待响应 / 下载 / 解码 / 就绪 / 失败`，携带已接收字节、可空总字节和错误信息。
- 从 `EhClient` 响应头/流读取 → `GalleryImageStore` 或缩略图服务 → 图片请求 → 当前显示控件传递状态。现有 `IProgress<long>` 下载调用者继续兼容，可新增重载或改为明确的结构化进度；归档下载不能因此回归。
- 有可信长度时显示真实百分比；无长度时使用不定进度并显示已接收大小，不能模拟百分比。`下载 100%` 与 `解码中` 是两个阶段，就绪后再移除遮罩。
- 网络卡住时仍显示等待/下载状态与重试，失败只影响该页，不把用户弹回详情。
- 单页模式在当前页占位处显示圆形进度和百分比；连续/横向模式在各可见图片内显示各自进度。后台预取进度不能替代当前图进度。
- `AsyncImage` 如增加可绑定状态，必须沿用现有 generation/cancellation 检查；覆盖单页所用 `ZoomPanView` 的请求路径。所有模式不能只修一种控件。
- 进度更新节流至约 100–200 ms，切 UI 线程时再次校验请求身份。控件回收、缩放重解码、离开页面需解除订阅。
- 同一资源共享下载时，各观察者能订阅现有传输进度；一个观察者取消不能误取消另一个仍需要的请求。可以保留既有分条锁，但不能长期在 UI 线程等待锁。

### 4.3 验收

- 模拟预览请求延迟 5 秒：点击后 500 ms 内可见阅读器占位和可用返回操作，且导航发生在网络响应之前。记录实际耗时与测试机器环境。
- 第一分页已返回、后续分页延迟时，第一张图照常显示；续读后部页面不等无关的全部分页。
- 模拟已知长度的慢速图片流：观察到多个递增的真实百分比；无长度流显示不定进度，成功、解码失败、超时均有正确终态。
- 快速翻页、连续滚动、返回和重新进入，不串页、不复活旧文档，不持续刷新已销毁控件。

## 5. 下载页直接阅读实际任务目录

- `DownloadTaskViewModel.ReadCommand` → `DownloadsViewModel` 发出明确的阅读请求，由 Shell/MainWindow 使用现有导航打开。请求至少带任务 ID、准确 `FolderPath`、GID/token、标题、预期页数及画质。
- 按任务目录扫描有效已完成图片，构造临时 `GalleryInfo`/本地阅读源。不得只按 GID 选择本地库首个副本，也不必为阅读自动加入整个下载目录。
- `AddAsSource=false`、自动入库关闭、本地库未初始化或正在扫描，均不能阻止读取已经落盘的有效页。
- 排除 `.part`、零字节、签名无效的文件。按钮可用性不能只相信持久化的 `DownloadedPages`；目录被移走或没有有效图片时，给明确状态，禁用或反馈原因，禁止无声返回。
- 未完成任务允许先阅读有效页；新增图片落盘后，合并该目录页列表，保持原始页号和阅读位置，不要求全库重扫或重新打开。订阅事件需在阅读器关闭后解除。
- 复用现有缺页和未完成进度语义，读到当前最后一张不能把整本标为完成。读写并发不能碰下载临时文件。

验收：关闭入库的下载、首张落盘立即点击、部分失败/暂停、重启恢复任务、同 GID 两个不同目录、文件被移走、下载中新增页；必须打开正确副本，或显示准确原因。

## 6. 在线收藏使用确认弹框，可靠核验结果

### 6.1 交互

- 在线详情点击“收藏/已收藏”打开 Fluent 原生 `ContentDialog`。展示 10 个真实分类名称，未收藏时由用户选择分类，确认后提交。
- 已收藏时选中当前真实分类，可换分类保存，或明确点击“取消收藏”；关闭弹框/取消按钮不修改服务器。
- 弹框内的分类选择仅改草稿，不发请求；移除当前详情页“修改 ComboBox 立刻提交”的路径。弹框打开后再读取分类状态时，不覆盖用户已修改的草稿。
- 未登录先提示登录；提交中禁用重复提交和冲突操作。维护每个作品串行的收藏变更；取消阅读详情时正确处理已经发出的提交结果。
- 分类采用稳定的 0–9 ID，名称允许重名和自定义，不能依赖显示名反推提交 ID。
- 同步在线详情、收藏列表和相关入口的状态；保存后保留原列表查询和位置。本地收藏是现有独立标记，不擅自同步到线上分类或修改其语义。

### 6.2 请求与结果

- 给当前失败模式建立响应夹具：成功但仍有表单、正常确认、登录过期、权限/站点错误、空响应、请求已应用但响应中断。
- 核对真实表单字段、编码、Referer 与返回跳转；先查证，再调整请求，不能因误报直接新增重试提交。
- 用明确结果区分 `成功 / 拒绝 / 结果未知`，替换含糊的关键词布尔判断。若响应不能证明结果，执行一次只读核验，读取收藏状态和当前分类。
- 读取 popup 的默认选中项不一定证明作品已收藏；核验必须结合详情的收藏状态。若分类无法可靠解析，显示已收藏但分类待核实，不默认为分类 0。
- 核验目标分类一致后再更新成功状态。若 POST 超时而结果未知，不提示确定失败，也不自动重复 POST；提供“重新检查”。
- 保留既有收藏备注，改分类时不要用空字符串意外清空远端备注；如需扩展 popup 状态模型，一并解析分类 ID 和备注。

验收：首次收藏取消无 POST；确认分类 7 只有一次 POST，服务器和 UI 都是 7；0→7、移除收藏、分类重命名、连续点击、提交中断后核验均正确。“提示失败但在 0 分类成功”的夹具必须失败后转绿。

## 7. 统一有界磁盘缓存与在线历史图片

### 7.1 扩展现有缓存

- 复用 `OnlineImageService`、`GalleryImageStore` 与 `AppPaths` 的缓存目录，不另建平行的图片缓存系统。缩略图、在线页图、读取所需的页引用索引纳入明确的预算与淘汰策略。
- 新设置建议：在线磁盘缓存上限默认 2048 MiB，可调 128–32768 MiB；保留时间默认 14 天，可调 1–90 天。作为本计划建议默认值，执行时结合控件范围验证，不复用 `PageCacheMegabytes`（它是解码内存预算）。
- 设置放在“浏览”分组，简短展示上限、保留时间、当前占用和“清除在线缓存”。清理放后台执行，完成后刷新占用量。
- 使用统一 LRU/最近使用记录：所有命中路径都更新使用记录，不能只在下载完成时记录。缩略图命中也要更新；不要假定系统会自动可靠维护访问时间。
- 启动后台检查、写入后触发合并清理、缩小预算时立即安排清理；不能仅等满 16 次写事件。命中和解码事件不能伪装成新写入反复触发全目录扫描。
- 原子落盘并校验签名；保护正在下载、解码、使用中的条目。允许的超额仅限受控的在途传输和受保护条目，释放后立即回收；测试需给出实际超额上界，不能只声称“有界”。
- 单张图片超过预算时，作为临时资源完成当前显示，使用完清理，不永久突破上限。过期 `.part` 文件纳入独立清理，不误删仍在传输的文件。
- 缓存键至少区分站点/访问上下文、作品身份、页号、画质和压缩尺寸；缩略图保留稳定作品引用以及 URL 映射。登出/切换账号或站点后不能展示上个访问上下文的错误结果。
- 清缓存不删除历史、阅读进度、作品元数据或正式下载文件。现有 `GalleryImageStore.FindLocalPage` 返回的下载文件不属于可淘汰缓存，必须区分所有权。
- 新设置支持旧配置缺字段的默认迁移、范围校验和源生成 JSON；应用设置保存后运行中的服务采用新策略。

### 7.2 历史封面与缓存续读

- 首次在线浏览/打开详情/在线阅读时，持久保存作品 thumbnail 引用和已下载的缩略图映射；仅写 URL 而没有缓存文件不构成离线可用。
- 历史封面优先级：存在且可读的本地封面 → 该作品已缓存缩略图 → 受缓存管线管理的网络加载 → 明确占位与可重试状态。
- 不能因为 `Item != null` 就永久选择失联的本地封面。旧记录缺 thumbnail URL 时，显示条目后异步、限并发补元数据；有 token 才请求详情，不阻塞整个历史列表。
- 在线已缓存页图与页引用索引可在返回历史、重启和离线时复用；未缓存页在断网时显示未缓存/重试，不声称全书可离线。缓存索引失效或访问被拒绝时给出准确错误。
- 不为每条历史预下载正文；只按用户浏览/阅读缓存。去重并限制补封面和元数据请求并发，避免打开历史发起请求风暴。

验收：无任何本地来源时，在线阅读→历史→重启仍有封面；断网能读已缓存页；源目录失联能回退；旧记录 URL 缺失、URL 过期、缓存被淘汰均有可辨状态。小预算并发访问、缩小上限、正在解码时清理、程序异常退出后重启都不破坏正式下载或进度。

## 8. 本地库下载遮罩、重复筛选与扫描入口

### 8.1 封面下载进度

- 将下载任务状态投影到本地卡片，按规范化目录/副本身份关联，不能仅以 GID 合并不同版本的下载进度。
- 正在下载时封面显示半透明遮罩、圆形确定进度和百分比；辅助文本用“下载中 · 12/76”。页总数未知时用不定进度。不要复用现有阅读进度字段。
- 待下载、暂停、失败用简短状态区分；下载完成自动移除遮罩，保留原封面和阅读进度，未完成的失败任务仍可阅读有效页。
- 分组卡片优先显示当前展示副本的任务；若正在下载的是其他版本，明确标注对应版本/任务，避免让完整主副本看起来缺页。多个任务不按 GID 随意平均百分比。
- 圆环采用 Fluent 现成控件；遮罩不截获阅读/详情/版本按钮输入；深浅主题都有足够对比度，并提供可读的辅助功能状态。
- 沿用下载事件合并更新；不能每个网络字节扫描目录、重建整个 ItemsSource 或重新排序，避免滚动跳动。

### 8.2 “重复”标签

- 在本地库现有筛选标签中增加“重复”，含义为同一作品有多个实际本地版本，即 `HasMultipleVersions`。
- 在 `LibraryFilter` 末尾追加枚举值，保持旧持久化数值不变；旧设置的过滤项仍可加载。
- 与现有来源、语言、搜索、排序正常组合；按当前有效来源的作品分组计数，不按标题相似度擅自合并作品。
- 下载新增副本、来源开关、目录迁移或版本变化后同步更新筛选成员和计数；卡片保留 `×N` 版本入口。

### 8.3 移动全量扫描

- 删除本地库工具栏“刷新”按钮，回收其 Grid 列，避免留下新的空白。
- 在“设置 → 本地库”提供“重新扫描全部来源”，调用现有强制扫描流程；显示扫描状态和可用取消入口。扫描/迁移中禁用重复启动。
- 处理 MainWindow 的本地库 F5 分支：不再静默触发全量扫描；可只更新现有投影或引导到设置。在线浏览 F5 保持刷新当前在线结果。
- 明确区分“清除扫描缓存”和“重新扫描”，不把清缓存悄悄变成全库扫描；正常启动缓存加载、单目录下载增量更新继续有效。
- 扫描异常或取消保留已有可用列表、过滤条件和位置；只读来源保持只读。

验收：单版本被排除，两个有效本地版本被纳入；移除第二来源后退出重复结果；点击卡片仍可阅读/看详情；下载进度与阅读进度互不覆盖；本地库无刷新按钮且 F5 不引发全库扫描，设置入口能启动/取消并显示结果。
