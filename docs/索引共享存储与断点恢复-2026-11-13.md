# 索引共享存储与断点恢复（2026-11-13）

本记录取代 [旧实现状态](IMPLEMENTATION-LOCAL-IMAGE-SEARCH-STATUS.md) 中“保留完整上一代”“跨重启断点尚未实现”的描述。计算后端加速仍见[加速方案](以图搜图索引加速方案-2026-11-13.md)，本次没有加入 SIMD / CUDA 后端，也没有测量真实全库的建库速度。

## 原因与新存储结构

原实现的更新快照复制包含描述子 BLOB 的 `images.db`，发布后还保留上一整代；失败的新代留下后，下次重新建立任务。这样既积累重复特征，又不能接续已提交页面。

新的索引根目录为：

```text
features.db                 唯一共享特征库：提取配置 ID + 内容哈希 → 描述子
build-job.json              未完成任务及阶段，完成后移除
current.json                已验证的当前快照指针
current.previous.json       发布清理后指向同一快照的备份指针
writer.lock                 跨进程写入锁
generations/<id>/
  .ehreader-image-search-generation
  manifest.db               来源副本 / 原始页号 / 文件签名 → 内容别名
  backend/images.db         内容 ID、别名、索引段检查点等元数据，不重复存特征 BLOB
  backend/quantizer.bin      不可变量化器
  backend/invlists.bin       已发布倒排索引
  backend/segment-*.ivf      构建中的已提交索引段
```

`generations` 继续作为原子发布和在途查询的隔离边界。正常完成后只保留当前快照；有未完成任务或旧查询仍在读取时暂时保留对应快照。**不再为了备指针永久保留一整份旧索引。** 备指针可恢复指针文件损坏，无法代替整份旧索引做数据损坏回退。

增量准备只备份元数据 SQLite；量化器与旧倒排索引优先创建硬链接，不支持时退回复制。构建通过独立新文件替换目标，绝不原位覆写共享文件；在途旧读取允许删除共享并由服务租约保护其目录。合并仍需要一份临时的新倒排文件，因此这不是“整个建库过程只占一份最终索引”的承诺。

## 持久化与接续

- 任务记录包括源配置身份、提取配置、候选快照、上一发布快照、图库标量快照、是否重新提取、启动恢复意图及准备 / 提取 / 训练 / 构建阶段；使用源生成 JSON 上下文与 `JsonFileStore` 原子保存。
- 共享特征先提交，再提交引用它的后端元数据，最后提交页面清单。每页清单是独立持久化检查点；重启时核对路径、大小、mtime，匹配的已完成页跳过解码和提取。
- 描述子已提交但页面清单尚未提交时，重新处理该页仍可按内容哈希复用共享特征。失败页重试；扫描移除的页面不保留旧清单 / 别名。
- 已提交索引段继续使用；段文件已写入但 SQLite 检查点未提交的孤立段被清理。未完成 `.part` / 合并候选文件会在接续时清理。
- 已完整写出的量化器可复用；若在训练内部中断，恢复后重新训练，不宣称从 k-modes 的中间迭代精确接续。
- 应用服务持有任务，关闭搜索页不取消。正常退出 / 异常中断后，初始图库扫描完成再自动接续；显式点击取消则持久化为暂停，重新打开页面显示“继续建立索引”，下次启动也不自动恢复；下载后自动更新同样不能越过这个暂停意图。
- 数据源设置变化时不盲目接续旧任务；原发布索引保持可用，等待用户按新配置更新 / 重建。

检查点读取、保存、完成移除以及指针发布由同一服务锁协调，避免状态读取短暂占用文件导致检查点保存失败。服务退出同时取消并等待状态读取、搜索和建库的后台文件操作，不依赖 UI continuation 释放句柄。

## 旧缓存迁移与回收

1. 只识别应用标记与 GUID 目录，拒绝经过链接、目录联接或导入库路径的存储；用户源文件始终只读。
2. 多个旧代中的描述子按配置 / 内容哈希迁入单份 `features.db`。每批先持久化共享数据，再删除已迁移的旧 BLOB，最后压缩已迁空的元数据库；中断后可以重复运行。
3. 对没有 `build-job.json` 的旧版未完成目录，排除已发布与备指针快照后，选择完成页最多的兼容候选接续。其他旧目录的特征也先迁入共享缓存，避免直接丢弃已有计算结果。
4. 成功发布后同步备指针，删除无在途查询的过期目录；旧查询结束会触发回收。保留未完成任务目录。删除失败或仍占用的目录保留，并参与共享特征引用计算。
5. 没有未完成任务时，删除所有保留快照都不再引用的共享描述子，使用 SQLite incremental vacuum 回收空闲页。内容 / 向量 ID 保留小型墓碑，避免新内容复用旧 ID；相同内容重新导入后重新入索引。

本次没有用新代码写入用户的 `J:\Cache\EhviewerIndexCache`，也没有删除用户给出的目录。迁移和回收由升级后的应用在恢复 / 更新 / 清理时执行；验证仅使用隔离合成资料库。
