# 在线卡片、合并入口与滚动加载验证（2026-11-13）

## 行为与设计

- 参照 `e7da9e1^`（实际文件路径为当时的 `src/EhViewerReader/ViewModels/OnlineFeedViewModel.cs`），恢复在线浏览页内的首页 / 热门 / 订阅 / 排行标签。主导航恢复六个入口；订阅和排行榜不再创建平行 ViewModel / 页面。保留新版本的排行榜总览、类型与周期选择、完整书签搜索条件。
- 标题下的独立一行显示评分和本地标识，页数 / 日期单独显示。本地标识移出图片，使用双主题不透明配色；本地库阅读按钮以不透明 `AppBgBrush` 隔离封面，原生按钮继续处理悬停、按下与禁用。
- 列表评分缺失的原因是 `EhParser.ParseGalleryList` 没有赋值 `Rating`。新增 `ir` sprite 位移解析，不为每张卡片增加详情或 API 请求；列表显示的是站点提供的半星精度，不等同于详情页的精确平均值。
- 在线画廊、搜索及收藏改为接近底部时滚动追加。沿用服务器的下一页 URL、GID 去重与 ItemsRepeater 虚拟化；移除上一页 / 下一页按钮和访问历史栈。切换标签、搜索、刷新时清空列表并取消旧请求，迟到响应不能进入新列表。
- 失败保留已加载内容和下一页地址，停止自动重试，提供“重试加载”。服务器返回重复续页地址时停止；连续三批没有可见增量时暂停自动续载并提供“继续加载”，避免过滤规则使应用不断请求。

## 真实站点证据与固定回归

先运行既有 `--online-probe`，隔离目录中为匿名会话，首页返回 25 项，探针成功。之后使用现有 `EhClient.GetStringAsync` 抓取匿名首页；原始记录位于 `.qa/cards-navigation-20261113/online-probe-before.json`、`front.html`、`capture.log`。

抓取到的评分片段包括 `background-position:-32px -21px;opacity:1` 和 `background-position:-48px -1px;opacity:1`。这些片段固定为 `tests/EhViewerForPc.Core.Tests/OnlineParserTests.cs` 回归，修复前分别错误地得到 0，修复后得到 2.5 和 2。边界测试覆盖满星、零星和畸形样式。位移含义还核对了 [EhViewer 的原始评分解析实现](https://github.com/seven332/EhViewer/blob/master/app/src/main/java/com/hippo/ehviewer/client/parser/GalleryListParser.java)。

真实站点仅做匿名只读探测，不写真实账号；滚动、取消、重试和列表切换的确定性测试使用本机 HTTP 服务。未验证登录账号的订阅内容或真实账号收藏写入。
