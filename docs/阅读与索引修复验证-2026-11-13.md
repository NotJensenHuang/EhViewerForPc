# 缺页阅读、书签与索引后台任务验证（2026-11-13）

> 后续在线卡片布局、订阅 / 排行入口及列表续载行为已由[在线卡片与滚动加载验证](在线卡片与滚动加载验证-2026-11-13.md)取代；本文保留当时的验证记录。

## 修复边界与原因

- 本地扫描只枚举存在的文件，原阅读器直接用该集合显示页数，导致缺页被折叠。现在 `LocalReaderSource` 按原始页号及预期页数建立完整页位，缺页不创建图片解码任务；单页、纵向连续、横向连续均在该位置显示缺失页号。保存进度仍按原始页号，缺页副本末页不标记完成。
- 阅读工具栏的选择框曾继承导航页头字体，窄窗口按钮仍保留原生控件较宽的最小宽度。选择框明确使用 13 DIP 常规字体，窄窗口图标按钮固定 36 DIP；更多菜单改由独立按钮承载并按右下角定位。
- 书签管理移出导航页，复用 `BookmarksView` 作为主窗口 `FAContentDialog` 的内容，不增加 Frame 历史。仅明确选择“编辑完整搜索条件”时展开高级选项，打开书签直接执行保存的查询。
- 在线卡片使用现有本地库索引显示“已在本地”或“本地缺页”，扫描后同步刷新，未新增平行状态源。
- 建库仍由 `AppServices.ImageSearch` 单一持有。页面生命周期只取消查询；建库取消令牌归应用服务管理，进度保存在服务并在 UI 线程合并发布。新页面可重新订阅；明确取消和应用退出会取消在途任务，退出时等待索引写入收尾。以图搜图页头状态与操作统一垂直居中。

